# Automação de Documentos Word com Excel e VBA

## Sobre o projeto

Projeto desenvolvido em VBA para automatizar o preenchimento de documentos Microsoft Word utilizando informações armazenadas em uma planilha Microsoft Excel.

A solução permite transferir informações automaticamente da planilha para um documento Word, preservando a formatação e a estrutura visual do modelo original.

## Objetivo

Reduzir o trabalho manual no preenchimento de documentos, minimizar erros de digitação e otimizar processos administrativos repetitivos.

## Tecnologias utilizadas

- Microsoft Excel
- Microsoft Word
- VBA (Visual Basic for Applications)

## Funcionalidades

- Leitura de informações armazenadas em planilha Excel.
- Integração entre Excel e Word.
- Preenchimento automatizado de campos do documento.
- Preservação da formatação do modelo Word.
- Geração de documentos a partir dos dados da planilha.

## Aplicação prática

A solução pode ser adaptada para diferentes cenários empresariais, como:

- Preenchimento de formulários;
- Geração de declarações;
- Emissão de documentos administrativos;
- Criação de contratos e relatórios;
- Automatização de documentos padronizados.

## Como utilizar

1. Baixe os arquivos do projeto.
2. Abra a planilha de exemplo.
3. Insira as informações nos campos correspondentes.
4. Execute a macro VBA.
5. Confira o documento Word gerado.
